% ==================== INTRODUCTION — Entraînement libre ====================
\fbox{\parbox{\dimexpr\linewidth-2\fboxsep-2\fboxrule}{%
  \textbf{Entraînement libre --- non noté.} Un exemple inédit de chaque
  type de question posée dans le QCM noté, même niveau et même piège, pour
  vous faire une idée du format avant l'épreuve --- les questions de
  l'épreuve seront différentes. Comme à l'épreuve, le symbole
  \multiSymbole\ après une question signale qu'elle admet plusieurs bonnes
  réponses ; les autres n'en admettent qu'une seule. Le corrigé est fourni
  à part.
}}
