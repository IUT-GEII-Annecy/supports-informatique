% ==================== INTRODUCTION — Entraînement libre ====================
\fbox{\parbox{\dimexpr\linewidth-2\fboxsep-2\fboxrule}{%
  \textbf{Entraînement libre --- non noté.} Ce document n'est \textbf{pas}
  un QCM AMC : il ne sera ni distribué en salle avec des cases à noircir, ni
  scanné, ni corrigé automatiquement. Il rassemble, pour chacun des types de
  questions posés dans le QCM noté sur les variables, les affectations, les
  conditions et les boucles, \textbf{un exemple inédit} du même niveau et du
  même piège, afin de vous permettre de vous faire une idée du format et de
  la difficulté \textbf{avant} l'épreuve. Les corrigés figurent directement
  dans ce document (bonne réponse repérée par \checkmark, ou corrigé rédigé
  pour les questions à rédiger) : utilisez-le pour vous auto-évaluer, pas
  pour le réviser « par cœur » --- les questions de l'épreuve seront
  différentes. Comme à l'épreuve, le symbole \multiSymbole\ après une
  question signale qu'elle admet plusieurs bonnes réponses ; les autres
  n'en admettent qu'une seule.
}}
