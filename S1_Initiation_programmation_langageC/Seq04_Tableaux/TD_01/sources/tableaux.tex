\begin{UPSTIexercice}{Amorce — la limite des variables séparées}
    Un enseignant veut calculer la moyenne de ses étudiants. Pour 3 étudiants, il écrit naturellement :
    \begin{lstlisting}[language=C]
#include <stdio.h>

int main(void) {
    float note1 = 12.0, note2 = 15.5, note3 = 9.0;
    float moyenne = (note1 + note2 + note3) / 3;
    printf("Moyenne : %.2f\n", moyenne);
}
    \end{lstlisting}

    \UPSTIquestion{Ce code fonctionne pour 3 étudiants. Ecrire ce même programme pour 5 étudiants.}
    \UPSTIquestion{Quel est le problème de ce programme pour 30 étudiants, voire une promo de 200 étudiants ?}
    \UPSTIquestion{Aussi, comment faire pour gérer un nombre d'étudiants variable, par exemple en lisant les notes au clavier ?}
\end{UPSTIexercice}

On voit qu'il est impossible de gérer ainsi une collection de données dont la taille est grande, ou simplement variable. Le langage C propose pour cela le \textbf{tableau} : une seule variable regroupant plusieurs valeurs de même type, repérées par un \textbf{indice}.
\begin{UPSTIinfor}{Les tableaux en langage C}
    \begin{itemize}
        \item Un tableau est une variable qui regroupe plusieurs valeurs de même type.
        \item Chaque valeur est repérée par un indice, qui commence à 0.
        \item La taille d'un tableau doit être connue à la compilation (constante entière).
        \item Les tableaux sont des variables locales, mais on peut les passer en paramètre à une fonction.
    \end{itemize}
    
    \textbf{Déclarer et utiliser un tableau :}
    \begin{lstlisting}[language=C]
    float notes[30];     // declare un tableau de 30 flottants
    notes[0] = 12.0;     // premier element : indice 0
    notes[29] = 9.5;      // dernier element : indice (taille - 1)
    \end{lstlisting}
    En C, les indices d'un tableau de taille $n$ vont toujours de $0$ à $n-1$ : c'est ce qu'on appelle l'\textbf{indexation 0-based}.
\end{UPSTIinfor}

\begin{UPSTIinfo}{Passer un tableau en paramètre}
    En C, lorsqu'on passe un tableau à une fonction, on ne passe pas le tableau entier, mais seulement l'adresse de son premier élément. Cela s'écrit dans la signature de la fonction par un paramètre de type tableau (ou pointeur) : \texttt{int t[]} ou \texttt{int *t}.
    
    La fonction reçoit donc \textit{un pointeur (nous verrons ce qu'est un pointeur plus tard)} vers le premier élément du tableau. La fonction doit absolument connaître la taille du tableau pour pouvoir le parcourir correctement. 

    \textbf{Lorsque l'on passe un tableau en paramètre d'une fonction, on doit \textit{toujours} passer sa taille en paramètre également.}

    \begin{lstlisting}[language=C]
void afficher_tableau(int t[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", t[i]);
    }
    printf("\n");
}
    \end{lstlisting}
\end{UPSTIinfo}

\begin{UPSTIexercice}{Tableau de caractères}
    En C, une chaîne de caractères est un tableau de \texttt{char} terminé par un caractère spécial, le \textbf{caractère nul} \texttt{'\textbackslash 0'}, qui marque la fin de la chaîne.

    \begin{lstlisting}[language=C]
char mot[] = "bonjour";
int i = 0;
while (/* a completer */) {
    printf("%c\n", mot[i]);
    i++;
}
    \end{lstlisting}

    \UPSTIquestion{Compléter la condition de la boucle pour parcourir le tableau jusqu'au caractère nul.}
\end{UPSTIexercice}
