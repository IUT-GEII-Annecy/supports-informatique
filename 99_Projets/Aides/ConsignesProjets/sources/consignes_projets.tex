\section{Consignes générales des projets}

\subsection*{Évaluation}
C'est la \textbf{soutenance} qui compte : la \textbf{compréhension du
code} que vous présentez et votre capacité à répondre aux
\textbf{questions} posées sur son fonctionnement. Un code qui fonctionne
mais que vous ne savez pas expliquer n'est pas considéré comme acquis.

\subsection*{Pendant la réalisation et la soutenance}
\begin{itemize}
  \item \textbf{Pas d'IA} : le code rendu doit être écrit et compris par
  vous-même.
  \item \textbf{Pas de téléphone.}
\end{itemize}
